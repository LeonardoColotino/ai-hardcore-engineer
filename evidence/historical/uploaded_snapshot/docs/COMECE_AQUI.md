# Comece aqui
1. Extraia o ZIP e abra PowerShell na pasta ai-hardcore-engineer-v3-evoluido.
2. Execute scripts/setup_windows.ps1.
3. Edite .env e configure AUTH_SECRET e DEMO_PASSWORD.
4. Execute scripts/run_windows.ps1 e abra http://127.0.0.1:8000.
5. Para índice offline: python -m app.rag.ingest --seed com Python da .venv; para real, siga README/Ollama.
6. Antes da submissão, finalize PRE_SUBMISSION.md. As pendências externas estão explícitas em LIMITATIONS.md.
