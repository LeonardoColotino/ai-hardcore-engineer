# Fixed acceptance criteria

Zero critical owner leakage, wrong account tools or contradiction between ticket/API/state. Deterministic pertinent tests all pass; justified pending integrations do not become approvals.
Routing/tools >=95% final evaluation, zero wrong account tools for products. Useful grounded responses >=90% when sufficient evidence, groundedness/relevance >=1.8/2 and no critical zero; fallback and abstention retain their own denominators. These are internal targets, not official scores.
Critical memory, ticket authorization/lifecycle and handoff scenarios must pass individually and repeatedly. Genuine LLM quality needs real Ollama execution and factual review; mocks prove contracts only.
Browser and Docker build/run/readiness/persistence approved only with actual runtime execution. Latency p50/p95 measured against configured budget; no fabricated runtime values. Independent validator may reject green tests.
REQ-MEM/ROUTE/GROUND/HITL/ENC/PERF/UI/INFRA-001 acceptance is specified in SPEC; QA adds adversarial and held-out cases independently without lowering criteria.
