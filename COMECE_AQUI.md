# Comece aqui

1. Leia README.md: separa teste offline sem Ollama de geração real opcional.
2. Leia VALIDATION_REPORT.md e LIMITATIONS.md: mostram resultados atuais e limites.
3. A versão contém revisões 1–6 consolidadas; não reaplicar patches antigos.
4. Para avaliação de código, execute pytest tests. Não é preciso API paga nem Ollama.
5. Para usar a aplicação em instalação nova, crie .env local com segredo/senha próprios e siga Docker no README. A distribuição não contém senhas ou banco.
6. evidence/current contém capturas atuais e execução do pacote limpo. evidence/historical* contém desenvolvimento anterior, incluindo falhas.
7. O vídeo final não foi gravado. ROTEIRO_VIDEO.md é roteiro, não comprovação de vídeo entregue.
